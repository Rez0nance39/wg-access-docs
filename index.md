# Политика конфиденциальности

Дата обновления: 16.05.2026

Настоящая политика описывает, какие данные обрабатывает Telegram-бот WG Access Bot и как они используются.

## 1. Какие данные обрабатываются

Бот может сохранять и обрабатывать следующие данные:

- Telegram ID пользователя;
- username пользователя, если он указан в Telegram;
- статус подписки;
- срок действия подписки;
- идентификаторы служебных сообщений бота;
- технические параметры персонального файла подключения;
- дату создания и обновления записей.

Бот не запрашивает и не хранит паспортные данные, адрес проживания, банковские карты, CVV-коды и другие платежные реквизиты.

## 2. Для чего используются данные

Данные используются только для работы сервиса:

- создания и учета пользователя;
- проверки срока действия подписки;
- продления доступа;
- выдачи персонального файла подключения;
- отображения статуса подписки;
- технической поддержки;
- предотвращения ошибок и повторной выдачи одинаковых технических параметров.

## 3. Платежные данные

Платежные данные обрабатываются платежным провайдером или эквайрингом. Бот не получает и не хранит полные данные банковских карт.

## 4. Передача данных третьим лицам

Данные не передаются третьим лицам, кроме случаев, когда это необходимо для работы сервиса, обработки платежа, исполнения требований закона или защиты прав владельца сервиса.

## 5. Срок хранения данных

Данные хранятся в течение срока использования сервиса и могут сохраняться после окончания подписки для учета истории обслуживания, обработки повторных обращений и предотвращения технических конфликтов.

Пользователь может запросить удаление своих данных через поддержку.

## 7. Безопасность

Владелец сервиса принимает разумные технические меры для защиты данных от несанкционированного доступа, изменения, раскрытия или удаления.

## 8. Назначение сервиса

Сервис предназначен для управления подпиской на защищенный удаленный доступ, получения персонального файла подключения и инструкций по настройке.

Сервис не предназначен для доступа к запрещенным ресурсам или обхода ограничений, установленных законодательством.
